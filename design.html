缓动函数

我在 2025 年 10 月之前一直感觉缓动函数不重要，直到开始写“回到页首”功能时才发现它的重要性
（╯°Д°）╯︵ ┻━┻ 纵享丝滑的感觉太爽了啊啊啊啊
我主要用两个 cubic-bezier，分别模拟两种不同的物理现象。点击下面的演示区可以体验一下差异

cubic-bezier(0.16, 1, 0.3, 1) — 吸附缓动

这是我原创的缓动函数。特点是开始极快，然后逐渐减速直到精准停止。像把磁铁的感觉。适用于 Hover、Active、scale 变化等小幅度运动场景来模拟按钮的质感

/* 吸附缓动 - 适用于小幅度运动 */
.button {
  transition: transform 0.3s cubic-bezier(0.16, 1, 0.3, 1);
}

.button:hover { transform: scale(1.08); }
.button:active { transform: scale(0.85); }

cubic-bezier(0.2, 0.8, 0.4, 1) — 平滑缓动

这是我从苹果的开发者文档《Human Interface Guidelines》中《借鉴》来的。特点是先快后慢，模拟真实世界中发力滑行制动的过程。适用于返回页首、渐入动画、开关切换等大幅度运动场景

/* 平滑缓动 - 适用于大幅度运动 */
.card {
  transition: transform 0.8s cubic-bezier(0.2, 0.8, 0.4, 1), opacity 0.8s ease;
}

背景原理

这个由多个动态光斑叠加而成的背景是在3.6.0版本被引入的
光斑会随着鼠标滚动产生视差效果，营造出一种漂浮感。背景由三层叠加而成：渐变底色层、光斑层和玻璃内容层

每个光斑都是一个径向渐变(radial-gradient)的圆形元素，使用半透明的颜色从中心向外逐渐变淡，位置用CSS变量控制，方便通过JS实现视差效果。点击下方卡片可逐层查看效果，第一张为完整叠加效果。
